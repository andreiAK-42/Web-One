# Оценка времени на проект🕒


* Шапка двух стараниц - 30 минут

### ``main.html``
* Контейнер с прыгуном со скалы - 30 минут
* Контейнер featured - 20 минут
* Контейнер с карточками стран - 1 час
* Форма для связи (для двух страниц) - 30 минут
* Форма Recent story entries - 1 час
* Footer для двух страниц - 15 минут

Итого: 4 часа

### ``blog.html``
* Контейнер с видео - 1 час
* Текстовые контейнеры в общем - 45 минут
* Grid с фото мест - 20 минут * 2 = 40 минут

Итого: 2,4 часа


### ``Контрольное время: 6,6 часов``
